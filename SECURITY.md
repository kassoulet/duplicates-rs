# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |

## Reporting a Vulnerability

To report a security vulnerability, please send an email to kassoulet@gmail.com with details of the vulnerability. We will respond within 48 hours.

## Scope & Guidelines

- **In Scope:** Vulnerabilities in supported versions affecting application integrity, confidentiality, or availability.
- **Out of Scope:** Social engineering, denial of service (DoS/DDoS) attacks, or automated scanner reports without proof-of-concept.

## Safe Harbor

We consider security research conducted in good faith under this policy to be authorized. We will not take legal action against security researchers who comply with these reporting guidelines.
